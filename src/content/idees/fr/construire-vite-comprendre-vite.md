## Accroche

## Un point

Avec l’IA, le goulot n’est plus le code, c’est la compréhension partagée.

## Faits

- « The bottlenecks are rarely, if ever, the coding » (le goulot n’est presque jamais le code), Allen Holub, « Lead Time », septembre 2026.
- Clare Liguori (AWS), au AI Engineer, été 2026 : selon elle, la variable n’est pas l’outil, c’est la façon de travailler ; le nouveau goulot est la vitesse de décision.

## Plan

1. Le gap de connaissance : devs, support, ventes, marketing, direction.
2. Pourquoi l’IA l’élargit.
3. Lever le pied sur le codage, pour que tous suivent.
4. L’alternative : des lots plus petits, livrés souvent ; une équipe cross-fonctionnelle.
5. Où ça s’arrête : lever le pied n’est pas livrer moins souvent.
6. Ce qu’on mesure : la maîtrise du produit, la satisfaction des utilisateurs.

Sur le dernier lancement qui s’est bien passé, comment le support et les ventes ont-ils appris ce qui changeait ?
